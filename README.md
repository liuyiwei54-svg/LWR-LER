# SEM LER / LWR 测量工具

运行：

```bash
python3 ler_lwr_app.py
```

流程：打开一张原始、俯视 SEM 图；程序会从 Verios/FEI TIFF 的采集元数据中读取 `PixelWidth` 并自动填入像素尺寸（nm/pixel）；拖动鼠标框住**一条竖直线**及其两侧背景；点击“分析选区”。若 TIFF 不含该元数据，才需要手动输入。

PNG、JPEG、BMP、GIF 等普通图像也可以导入；它们通常不保存 SEM 像素尺寸，所以导入后直接在“像素尺寸 (nm/pixel)”输入框填写你的标定值即可。

可直接从 Finder 把 TIFF 拖进窗口导入。点击“查看 TIFF 元数据”可检查完整的 SEM 采集信息，包括 PixelWidth、视场、加速电压、探测器、工作距离、扫描参数等（若图像本身保存了这些信息）。

程序为单窗口、单实例：再次启动时只会提示使用当前窗口，不会打开第二个主窗口。在现有窗口导入另一张图时，会先确认并替换当前图像与结果，不会累积多个图像窗口。

## 图像浏览快捷方式

- 使用图像下方的缩放条，或点击 `−` / `+`，调整图像大小。
- 按住空格并滚动鼠标滚轮：以鼠标位置为中心缩放。
- 按住空格并按住鼠标左键拖动：平移图像。
- 未按空格时，鼠标左键拖动仍用于框选分析 ROI。

默认会进行 1%–99% 强度归一化和轻度 3×3 中值去噪，改善 SEM 画面的可见性并抑制孤立噪点。原图仍会保留；取消“归一化 + 3×3 去噪”即可用原始灰度数据测量。trim 前后对比时，建议所有图统一使用同一个预处理开关。

程序默认显示和导出 `1σ`。窗口内的滑块可设为 `0.5σ–6σ`，会实时更新 LER/LWR；CSV 会同时保存原始 `σ` 与选定倍数后的值。

## 指标定义

- `LER_L`、`LER_R`：左右单边边缘位置分别减去各自的线性最佳拟合后，按 `sqrt(sum(x²)/(N-2))` 计算。
- `LWR`：逐点宽度 `W = X_right - X_left` 减去平均宽度后，按 `sqrt(sum(w²)/(N-1))` 计算。
- `总边缘 RMS`：`sqrt(LER_L² + LER_R²)`，仅作诊断，**不是 LWR**。
- `ρ`：左右边缘残差的相关系数。`ρ` 接近 1 时两边会一起移动，LWR 可很小；`ρ` 接近 -1 时线宽起伏会增大。

行业标准术语是 LER（Line Edge Roughness）和 LWR（Line Width Roughness）；“EWR”并不是此类计量中通行的标准缩写。

## 倾斜图案

目前的边缘提取沿图像竖直方向采样，因此分析倾斜线前，应先框选含有单条线和两侧背景的 ROI，点击“自动校正 ROI 倾角”。程序使用 ROI 中边缘梯度的主方向估计倾角并旋转图像；随后必须在校正后的图像上重新框选 ROI 并分析。旋转会使用双三次插值，所以 trim 前后比较时应统一采用同一校正流程。

目前为 MVP 版本：适用于近似竖直、对比度充分的单根线条。正式开展 trim 前后比较时，必须固定 SEM 成像条件、像素尺寸、ROI 长度和边缘提取参数，并使用不带比例尺/文字/人工标注的原始图区。
