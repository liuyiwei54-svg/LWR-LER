# SEM 测量工具（LER/LWR + BCP 点阵 + 尺寸标注）

## macOS 安装包

发布版软件名为 **SEM measure**。Apple Silicon Mac（M1、M2、M3、M4）用户可从 GitHub Releases 下载 `SEM measure-macos-arm64.dmg`，双击打开后将 `SEM measure.app` 拖入“应用程序”文件夹。

发布安装包不需要 Python。源码维护者可从项目根目录运行 `./build_macos_app.sh` 重新构建 macOS 应用；构建输出保存在 `release/`，不应提交到 Git。

## macOS 安装包

发布版软件名为 **SEM measure**。Apple Silicon Mac（M1、M2、M3、M4）用户可从 GitHub Releases 下载 `SEM measure-macos-arm64.dmg`，双击打开后将 `SEM measure.app` 拖入“应用程序”文件夹。

发布安装包不需要 Python。源码维护者可从项目根目录运行 `./build_macos_app.sh` 重新构建 macOS 应用；构建输出保存在 `release/`，不应提交到 Git。

运行：

```bash
python3 ler_lwr_app.py
```

流程：打开一张原始、俯视 SEM 图；程序会从 Verios/FEI TIFF 的采集元数据中读取 `PixelWidth` 并自动填入像素尺寸（nm/pixel）；展开顶部“分析功能 ▸”，点击“测量 LER / LWR”。Scharr/Canny 显示检测到的边缘，不会自动配对边缘或计算 CD/LER/LWR；拉普拉斯对选定区域进行单线 LER/LWR 测量；“单边测量（ERA）”则让用户分别框选一根线的左、右单边 ROI，并可一次建立多根线样本。若 TIFF 不含该元数据，才需要手动输入。

这也是一个可扩展的通用 SEM 尺寸标注工具：在主图像左侧“通用标注”工具列选择 `长度`、`矩形`、`圆形` 或 `正六边形`，然后在图上拖动创建。标注会显示长度、宽高、直径或六边形边长/对角尺寸，点击已有标注可移动，拖动白色控制点可调整。独立的“标注选择”工具提供 `框选标注`：它只用于临时框选已有标注，松开鼠标后框会自动消失，不产生尺寸、标注或导出数据。填写 `nm/pixel` 后通用标注显示单位为 nm，否则以 px 显示。通用标注与绿色 LER/LWR ROI 相互独立。

顶部最左侧的 `菜单 ▾` 集中提供打开 SEM 图像、查看 TIFF 元数据、异常点剔除档位、`拟合线条样式`、CSV 和标注/拟合图片导出。`图像处理 ▸` 与 `分析功能 ▸` 都可折叠以节省空间；后者包含 LER/LWR、BCP 与二维 FFT 三个独立工作窗口。LER/LWR 测量窗口会保持在主窗口上层，便于在主图上框选 ROI；它只负责设置、框选和执行，计算后的结果与多线 LCDU 管理都在主窗口右侧。长度测量线带有两端垂直短横，便于识别准确起止点；左侧工具列的 `长度线颜色` 可为下一条长度线选色，或在选中已有长度线时直接修改它的颜色。`拟合线条样式` 可分别调整 LER/LWR 左右拟合边缘的颜色和共同粗细，画布与导出图片同步更新。CSV 同时保存通用图形的像素坐标和显示尺寸；图片导出会保留通用尺寸标注，并在有 LER/LWR 分析时同时保留左右拟合边缘。旋转分析图像后，导出图片仍保持原始 SEM 方向。

## 二维 FFT：频谱、相位与坐标谱

展开 `分析功能 ▸` 后点击 `二维 FFT 频谱 / 相位`。无需框选时直接点击 `计算 / 刷新`，程序将分析完整的当前预处理灰度图；若只希望分析局部纹理，先点击 `框选 FFT 区域`，再回到主图拖出橙色虚线框，然后点击 `计算 / 刷新`。FFT 选区独立于绿色 LER/LWR ROI，不会覆盖或改变 LER/LWR 的测量范围。

程序在计算显示频谱前会减去区域平均强度（去除直流背景），默认再应用 Hann 窗以减轻矩形截断引起的频谱泄漏；若需要严格保留原始矩形窗口，可选 `不加窗`。输出窗口并排显示中心化的对数功率频谱（中心是零频）、使用循环色相编码的相位图和逆变换重建图。另有三个按需展开、默认折叠的显示图：频谱下方的 `频域图 ▸` 显示 `fy = 0` 的 `fx / log I` 功率剖面；重建图下方的 `时域图 ▸` 显示原图与当前重构图的中心水平空间剖面；相位图下方的 `三维图 ▸` 显示 `fx / fy / log I` 的三维频谱曲面。六个区域均使用可拖动分隔条：可拖动两条竖向分隔条改变三列相对宽度，展开下方图后也可拖动该列的横向分隔条改变上下两图的相对高度。它们均为直观显示，未调用时不占用窗口空间，不会改变 FFT 数值、频率遮掩或重建结果。点击频谱或相位图任意像素会显示对应的 `fx`、`fy`、幅值、功率强度和相位（rad）；已有 `nm/pixel` 标定时频率坐标为 `cycles/nm`，否则为 `cycles/pixel`。FFT 窗口不是主窗口的附属窗口，因此可单独放在另一块显示器上使用。

频率编辑区提供两种滤波方式：点击 `遮掩频率（在图上拖动）` 后，可在频谱或相位图上拖出任意矩形；或先点击一个频率点自动填入 `fx`、`fy`，再点击 `删除该频率点` 精确删除。需要微调时，使用 `精细遮掩笔刷` 或 `精细恢复笔刷`：半径设为 `0` 时一次只修改一个离散频率格，拖动一笔可连续修改多个频率格；笔刷与 `恢复该频率点` 均会同步处理共轭频率。频谱、相位和重建图各自在图像上方提供独立的 `缩小`、`放大`、`适合窗口` 与 `拖动` 控制；点击 `拖动` 后在对应图上按住左键平移一次。三张图的倍率和位置互不影响，且没有键盘或滚轮缩放快捷键。缩放不会改变频率栅格，拖拽和点选始终对应原始 FFT 的准确频率点。每次删除都会自动删除共轭镜像频率 `(-fx, -fy)`，因此逆变换仍保持实数图像。黑色频率格表示已遮掩；点击 `逆变换重建` 可得到当前 FFT 区域的滤波重建图（整图 FFT 则得到整图）。重建采用未加显示窗的原始复频谱，以便在未遮掩时精确还原输入图像；Hann 窗只影响频谱/相位的显示。`恢复全部频率` 可取消所有遮掩。点击 `导出 PNG + CSV` 会生成遮掩后的频谱 PNG、相位 PNG、重建 PNG，以及逐频率点的 CSV（含 `frequency_x`、`frequency_y`、`magnitude`、`intensity`、`phase_radians` 和 `mask_kept`）。图像、预处理或旋转改变后，FFT 结果会自动失效，需重新计算。

PNG、JPEG、BMP、GIF 等普通图像也可以导入；它们通常不保存 SEM 像素尺寸，所以导入后直接在“像素尺寸 (nm/pixel)”输入框填写你的标定值即可。

## 垂直 BCP 点阵识别

对于垂直站立、俯视图中呈点状的 BCP，打开图像后展开顶部的 `分析功能 ▸`，点击 `识别 BCP 点阵`。导入时会自动检测并裁掉底部连续的 SEM 仪器信息栏；程序随后对完整成像区进行识别，不需要逐点框选：

- 绿色轮廓：每个已识别二值连通区域的真实像素边缘；黄色小点：对应区域的几何质心。首次识别和每次局部补漏后都会立即显示质心，不必等待 CD/Pitch 最终计算；结果给出等效直径、区域长轴和短轴的平均值与直径标准差。
- 蓝色线段：由所有柱子几何质心建立的局部 Delaunay 三角网，用于相邻关系与 Pitch 测量。程序先把 Delaunay 边作为候选，再自动剔除相对两端局部 Pitch 过长、非双向近邻，或被中间柱子中心阻挡的连线，避免图像边缘跨越中间柱子的强制连接。完成计算后可独立勾选是否显示蓝色三角网；显示时还可选择全部方向，或仅显示自动拟合的主方向、主方向 `+60°`、主方向 `−60°`。这些选项只改变画布和导出标注图，不改变统计结果。
- 彩色半透明晶粒叠加层：先以局部 Delaunay 邻居的六重对称晶格取向为依据，将取向差小于 `8°` 的相邻柱子归入同一晶粒；同一晶粒以同一种半透明颜色覆盖其质心近邻区域。这样可以直观看到晶粒分区及其交界。取向差达到 `8°` 以上的邻接边仍会记录为晶界候选并写入 CSV，但不再以单独红线覆盖图像。识别窗口中可独立勾选“显示晶粒取向叠加层（彩色）”；取消勾选只隐藏画布和导出图中的彩色层，不会改变晶界计算、CD、Pitch 或 CSV 数据。
- 质心虚拟圆柱布局：所有虚拟圆均以已识别的**原始质心**为圆心，并统一采用当前测得的平均 CD 作为直径，半径严格为该直径的一半。图像中心最近的真实质心额外标为锚点。Pitch 保留用于点阵周期、邻居关系和后续位错比较，但不会把显示圆心移动到另一套理想格点。可独立勾选“显示质心虚拟圆柱布局（显示锚点）”，并在 BCP 样式区调整虚拟圆轮廓的颜色、粗细和锚点颜色；该层不改变识别、CD、Pitch、晶粒或 CSV 结果。
- CD：从区域内质心沿水平、`+60°`、`−60°` 三条轴向边界发射相反射线，轴向 CD 为两侧半径之和；结果显示所有柱子平均 CD 及其标准误差。Pitch 取通过局部邻居筛选后的 Delaunay 边长，分别输出三个六方方向及合并全部方向的总平均值与可选的 `kσ` 波动范围。顶部“显示/导出倍数”滑块同时控制 LER/LWR/LCDU 或当前 BCP Pitch 的显示与 CSV 导出，默认 `k=1`，范围 `0.5–6`。
- `菜单 ▾` 的 CSV 导出会包含每个点的区域质心、等效直径、三方向 CD、长短轴、区域角度、面积、三角网边与晶界候选区域；标注图片也会保留绿色轮廓、蓝色三角网和红线。

点击 `识别 BCP 点阵` 会打开识别窗口。窗口分为“样本与局部分割（可选辅助）”和“识别”两栏。若知道柱子的大致直径，可在“识别”栏输入数值并选择 `nm` 或 `px`；填写 `nm` 时程序会用像素尺寸自动换算为 px。这个数值用于 DoG 尺度和区域尺寸筛选，不会直接覆盖最终测得的尺寸。局部分割是可勾选的保险层：启用时，按用户设置的横向 × 竖向网格（默认 `4 × 4`）切开整张图，每个网格块在当前响应图上独立计算阈值并生成 0/1 二值掩膜；关闭时，程序使用整图阈值。二值连通区域会先忽略完全包在柱子内部、面积不超过“柱内空洞忽略上限”的小暗斑，再删除小于最小面积的碎片；这类内部纹理不会形成小内圈，也不会扣减柱子面积。每个保留区域直接作为一根柱子并描绘真实像素外轮廓；不再使用局部峰值、点阵周期去重或分水岭拆分。最小面积默认 `0.25 ×` 样本圈面积；无样本时改用输入柱径对应的圆面积。柱内空洞忽略上限默认 `0.12 ×` 参考面积，设为 `0` 可关闭。识别后的绿色轮廓和红色晶界候选可用“清除当前结果”一键取消。

输入大致柱径后可直接点击“开始识别”进行自动识别；若不输入柱径，则先点击“标示/编辑样本”，圈出**至少 3 个**清晰、孤立的代表圆柱外缘。蓝色样本圈是可选但推荐的辅助信息，可继续添加任意数量并反复微调：拖圈内部可移动，拖外缘或白色控制点可调整大小，空白处拖动才会新增样本。样本圈不能重叠，避免把同一柱子重复作为训练依据。样本存在时用于确定亮/暗极性、柱径尺度、最小面积基准和全图尺寸校准；没有样本时，程序将亮点与暗点分别走同一条响应图、二值区域与连通区域流程，再结合原图的“区域内部相对外环亮/暗对比”和点阵支持度选择正确极性。响应图由“BCP DoG 对比增强”开关决定：启用时使用 DoG，关闭时使用原始亮暗强度。每个保留连通区域只输出一次，不会受柱子内部亮度起伏产生多个局部峰值的影响。识别后样本圈会自动隐藏，但校准数据和 CSV 样本记录会保留；如需显示或导出样本圈，可勾选“显示标准样本圈（画面/导出）”。

整图识别后，程序先只显示绿色轮廓，不立即显示或锁定 CD、Pitch、三角网和晶界。若仍有遗漏，可在识别窗口的“局部补漏”中点击“添加补漏区域”，在图上按住左键徒手画出不规则区域；可重复添加多个区域，全部选好后一次点击“识别所选区域”。每个区域各自计算局部阈值，结果会依次合并；已有轮廓始终保留。局部结果只会补充框内新出现、且不与现有**实际二值像素区域**相交的轮廓。程序不使用局部峰值或中心距离去重。框选时请包含漏柱及其周围少量柱间背景；`Backspace`、`Delete` 或“清除框选”可取消所有待识别区域并重画。若两个柱子已粘成一个绿色轮廓，可在“手动分割粘连柱”中点击“画分割线”，让橙色虚线完整穿过一个粘连处，再点击“执行分割”；程序只从该连通区域移除这条 3 px 宽的线并重新计算分割后的实际像素区域。分割线不可同时穿过两个绿色轮廓，分割后必须保留至少两个有效区域。确认所有柱子完整后，点击“完成补漏并计算 CD / Pitch”，才会生成蓝色三角网、红色晶界候选、CD 和 Pitch 统计；若之后再补漏或手动分割，这些最终结果会自动隐藏，需再次确认计算。识别窗口中的“BCP 线条样式（画面/导出）”可分别调整绿色轮廓、蓝色三角网的颜色与 1–6 px 粗细，以及黄色几何质心点的颜色与 3–12 px 直径；这些设置只影响显示和导出，不会改变识别或统计。

建议使用对比度充足、没有比例尺和文字覆盖的原始俯视 SEM 图。算法直接从局部分割后的二值连通区域描绘轮廓；若多个柱子在二值图中连成同一片，可先调整局部分割或 DoG，仍无法分开时再使用手动分割。填写 `nm/pixel` 后，BCP 尺寸和点阵间距以 nm 输出；否则以 px 输出。

可直接从 Finder 把 TIFF 拖进窗口导入。点击“查看 TIFF 元数据”可检查完整的 SEM 采集信息，包括 PixelWidth、视场、加速电压、探测器、工作距离、扫描参数等（若图像本身保存了这些信息）。

程序为单窗口、单实例：再次启动时只会提示使用当前窗口，不会打开第二个主窗口。在现有窗口导入另一张图时，会先确认并替换当前图像与结果，不会累积多个图像窗口。

## 图像浏览快捷方式

- 使用图像下方的缩放条，或点击 `−` / `+`，调整图像大小。
- 按住空格并滚动鼠标滚轮：以鼠标位置为中心缩放。
- 按住空格并按住鼠标左键拖动：平移图像。
- LER/LWR 窗口可选框选 ROI：点击“框选 / 调整 ROI”后在主图拖动绿色框；有框时，Scharr、Canny 和拉普拉斯都只使用框内图像，无框时都使用整图。Scharr/Canny 仅显示该区域的边缘，不进行边缘配对或 LER/LWR 计算。拉普拉斯则对输入区域进行单线 LER/LWR 测量。ERA 的“框选左边 ROI / 框选右边 ROI”是另一套显式的单边选择：每个框只应包含一条边的灰度过渡；只有存入同一“线样本”的左右边才会在共同扫描行上计算 CD/LWR。可新建多个线样本后一次分析，画布以青色/橙色虚框保留已保存的左右 ROI。ERA 有至少两根完整线样本时，会自动以这些线的 CD 计算 LCDU；这个自动 LCDU 会优先显示和导出，修改 ROI 或线样本后会自动刷新，不会重复加入手动 LCDU 池。可选勾选“去除孤立短噪声”：它只保留在 41 px 高 × 3 px 宽区域内有至少 24 个边缘点的既有像素；默认关闭。
- 在左侧工具列选择通用测量工具后，鼠标拖动会创建对应图形；点击已有图形优先进入调整。
- `Backspace` / `Delete`：删除选中的通用标注；在 LER/LWR ROI 框选模式下则删除 ROI。
- `Command + Z`（Windows/Linux 也可用 `Ctrl + Z`）：撤销最近一次 ROI 或通用标注的创建、调整、删除、清空、长度线改色，或旋转造成的编辑状态变化。导入新图后会开始新的撤销历史。

顶部的“图像处理 ▸”可展开独立设置。默认启用 1%–99% 强度归一化、3×3 高斯模糊和 BCP DoG 对比增强；平滑可切换为高斯模糊或均值模糊，核可选 `3×3`、`4×4`、`5×5`、`7×7`、`9×9`、`11×11`，预览矩阵会实时变化。高斯模式的 `σ（相对默认）` 滑块中，`1.00（标准）`保留原来的二项式权重矩阵，调小会减少平滑、调大会加强平滑；均值模式使用等权矩阵。LER/LWR 窗口的“边缘检测”默认使用可调 Scharr 核（斜向权重 3、轴向权重 10），也可选 Canny（可调 Sobel 核、非极大值抑制和双阈值滞后连接）、拉普拉斯或单边测量（ERA）。ERA 不使用 Scharr/Sobel/Laplacian 卷积核，也不额外执行论文中的 5×7 空间滤波：它直接使用当前预处理图像。对每个用户框选的单边 ROI，先根据灰度差分的预期方向计算四次幂加权重心，再在其附近拟合可选的 2/3/4 次多项式（默认三次），取方向正确、位于拟合区且最接近重心的归一化 0.5 交点作为该行边缘位置。两条边的灰度函数从不一起拟合；CD/LWR 只由用户明确归为同一线样本的两条独立轨迹得到。多线总 LER/LWR 用每根线独立去趋势后的残差平方和及相应自由度汇总，CD 为各完整线样本平均 CD 的平均。Scharr/Canny 的一阶卷积核可选 `3×3`、`5×5`、`7×7`、`9×9`、`11×11`；`3×3` 保持原有 Scharr/Sobel 矩阵，较大尺寸在计算梯度时扩大双项式平滑支撑，不是对边缘结果的后处理模糊。ROI 存在时，三种检测器都只处理框内；无 ROI 时处理整图。Scharr/Canny 不用梯度角度排除任何方向。可选“去除孤立短噪声”默认关闭；开启后才保留在 41 px 高、3 px 宽局部区域内具有至少 24 个支持点的既有边缘像素。Canny 使用 `highTh`（默认 `0.125`）和 `Rio`（默认 `2.5`），自动得到 `lowTh = highTh / Rio`；它先按非零 NMS 响应的 P99 做鲁棒归一化，再执行阈值连接。未通过连接的扫描行不会进入 LER/LWR 统计。检测器、核尺寸、核权重、Canny 参数、推导的低阈值和 P99 缩放值会写入 CSV；ERA CSV 另存多项式次数、极性、每条单边轨迹 ROI 和每线/总体结果。切换 DoG 会立即刷新画布：启用时显示 DoG 局部对比预览，关闭时显示常规预处理图；LER/LWR 始终使用常规预处理图，BCP 识别也只在流程中应用一次 DoG，不会二次增强。原图始终保留。trim 前后对比时，建议所有图统一使用同一组图像处理和边缘检测设置。

程序默认显示和导出 `1σ`。顶部原有的“显示/导出倍数”滑块可设为 `0.5σ–6σ`：当前为 LER/LWR/LCDU 结果时更新这些指标，当前为 BCP 结果时更新 Pitch（各方向与总平均）的波动范围；CSV 会同时保存原始 `1σ` 与选定倍数后的值。

“异常点剔除”默认是 `标准（12 px，默认）`，与原来的程序参数相同：边缘位置相对附近 9 行的局部中位数偏离超过 12 px 就不参与 LER/LWR 统计。可在分析前改为 `严格（8 px）`，更积极排除跳点；或改为 `宽松（16 px）`，保留更多可能有真实起伏的点。每次重新打开软件都会恢复为标准档，CSV 会记录本次使用的阈值。

## 指标定义

- `LER_L`、`LER_R`：左右单边边缘位置分别减去各自的线性最佳拟合后，按 `sqrt(sum(x²)/(N-2))` 计算。
- `LWR`：逐点宽度 `W = X_right - X_left` 减去平均宽度后，按 `sqrt(sum(w²)/(N-1))` 计算。
- `总边缘 RMS`：`sqrt(LER_L² + LER_R²)`，仅作诊断，**不是 LWR**。
- `ρ`：左右边缘残差的相关系数。`ρ` 接近 1 时两边会一起移动，LWR 可很小；`ρ` 接近 -1 时线宽起伏会增大。

行业标准术语是 LER（Line Edge Roughness）和 LWR（Line Width Roughness）；“EWR”并不是此类计量中通行的标准缩写。

## 倾斜图案

Scharr/Canny 显示输入区域内的全部检测边缘，不预设边缘属于哪一条线；输入区域可由 ROI 指定，也可为默认整图。拉普拉斯对同一输入区域沿图像竖直方向采样计算 LER/LWR。自动校正 ROI 倾角仅用于拉普拉斯；Scharr/Canny 若图像整体倾斜，可先使用主界面底部的手动旋转，然后重新识别。旋转会使用双三次插值，所以 trim 前后比较时应统一采用同一校正流程。

目前为 MVP 版本：适用于近似竖直、对比度充分的单根线条。正式开展 trim 前后比较时，必须固定 SEM 成像条件、像素尺寸、ROI 长度和边缘提取参数，并使用不带比例尺/文字/人工标注的原始图区。
